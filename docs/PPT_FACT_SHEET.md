## 1. 서비스 개요
- 전생여지도는 전주 원도심 4개 거점과 국립전주박물관을 잇는 모바일 웹 체험입니다. [C09]
- 4곳에서 "전생 조각"을 모으고, 박물관에서 나의 전생 캐릭터를 확인합니다. [C11, C13, C16]
- 지금 버전은 서버 없이 브라우저만으로 동작하는 **시연용 프로토타입**입니다. [C01, C15, R05]

## 2. 사용자 여정
1. `시작하기` → 로그인 → 튜토리얼 → 이름·생년월일 입력 → 지도 [C02, C03, R04]
2. 추천 순서: 완판본문화관 → 경기전 → 남부시장 → 전라감영 → 국립전주박물관. 순서는 자유입니다. [C09, C49]
3. 거점 QR을 스캔하면 그 자리에서 조각 1개와 시연용 쿠폰 1장을 받습니다. [C11]
4. 조각 4개를 모으면 박물관이 열리고, 박물관 QR 인증(또는 GPS 300m 확인) 후 결과를 봅니다. [C13, C47]
5. 결과 화면에서 미디어월 전시 동의 여부를 선택하고, 기념품 스토어를 둘러볼 수 있습니다. [C26, C34]

## 3. 핵심 기능 (검증된 표현)
- **조각 4종**: 시대(경기전)·신분(전라감영)·이야기(완판본문화관)·소지품(남부시장). [C09]
- **조각 문구 결정**: 생년월일·첫 방문 거점·세션 ID로 5개 원형 중 하나를 골라 정합니다(AI 아님). [C17]
- **최종 결과**: 미리 만든 캐릭터 콘텐츠(이미지·음성·스토리) 중 무작위로 보여 줍니다. **현재 등록된 캐릭터는 1종**입니다. [C18, C19]
- **쿠폰**: 4개 카테고리 × 3종 = 12종 중 무작위 발급, CODE128 시연 바코드. 실제 제휴처가 아닌 "제휴 예정 모델"입니다. [C21, C22]
- **기념품**: 14종(11,000~49,000원). 결제는 실제 청구가 없는 시연 화면입니다. [C24, C25]
- **미디어월**: 박물관 미디어월 콘셉트 영상(고정 파일)을 전체 화면으로 재생합니다. [C36]
- **전시 동의**: 동의 여부를 이 브라우저에 기록합니다. 실제 디스플레이 송출은 아직 없습니다. [C34, C35]
- **운영 대시보드**: 발표용 **가상 데이터**에 지금 시연 중인 기록 1건을 더해 보여 줍니다. [C27]
- **한국어 UI**: 한국어 달력, 한지·단청 톤 UI, 모바일 우선 반응형. [C45, C48]

## 4. 기술 스택
- React 19 · TypeScript · Vite 8 · Tailwind CSS 4 [C44]
- jsQR(브라우저 QR 해독), JsBarcode(CODE128) [C38, C22]
- 패키지 매니저 bun, 정적 사이트로 Vercel 배포 설정 [C43, C44]

## 5. 아키텍처·배포
- 모든 처리(인증 판정·조각·쿠폰·결과)는 **브라우저 안**에서 이루어지며, 서비스 서버로 데이터를 보내지 않습니다. [C15, R05]
- 데이터는 사용자 브라우저의 sessionStorage·localStorage에만 저장됩니다. [C33]
- Vercel에는 정적 파일(HTML·JS·이미지·영상)만 배포하도록 설정되어 있습니다. 서버리스 API·DB는 없습니다. [C43]
- Express 서버·SQLite·Gemini 연동 코드는 저장소에 남아 있지만 **현재 배포에서는 실행되지 않습니다.** [C40]

## 6. 개인정보
- 카메라는 QR 해독에만 쓰고, 영상·사진을 저장하거나 전송하지 않습니다. [C38, C39]
- 얼굴 인식·얼굴 사진 수집 기능은 없습니다. [C16, C38]
- 이름·생년월일은 해당 브라우저 탭의 sessionStorage에만 저장됩니다(보통 탭을 닫으면 사라짐). [C33]
- 단, 전시에 동의하면 이름 앞 6자가, 회원가입을 하면 계정 ID·이름·비밀번호 해시가 그 브라우저의 localStorage에 남습니다. [C28, C34]
- 로컬 빌드에서 확인한 외부 요청은 웹 폰트(CDN) 불러오기뿐입니다(Google 로그인을 설정하면 Google 스크립트도 불러옴). [R05, C30]

## 7. 시연 한계 (발표에서 함께 밝힐 것)

- QR 인증은 현장 방문을 증명하지 않습니다(QR 이미지만 있으면 인증 가능). [BUG-01]
- 로그인은 시연용입니다(서버 인증 없음). [C28, C30, C31]
- 등록된 캐릭터가 1종이라 모든 참여자의 결과가 같습니다. [C19]
- 쿠폰·결제·통계는 모두 가상입니다. [C21, C25, C27]
