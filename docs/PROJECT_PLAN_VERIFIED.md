## 1. 프로젝트 개요

### 1.1 이름
**전생여지도(前生輿地圖)** — 전주 원도심 거점을 돌며 "전생 조각"을 모으는 모바일 웹 체험 (저장소 `jeonju-yeojido`)

### 1.2 기획 의도 (목적)
- 완판본문화관·경기전·남부시장·전라감영·국립전주박물관을 하나의 체험 동선으로 연결
- 원도심에서 국립전주박물관 방면으로 관광객 이동 유도
- 거점마다 제휴 쿠폰을 주어 지역 소비 연결(현재는 가상 쿠폰)
- 체험 결과를 박물관 미디어월 전시로 연결(현재는 동의 의사 기록까지만 구현)

### 1.3 컨셉과 대상
- 한옥·달항아리 풍 시작 화면("어서 오시게, 전생을 찾으러 왔는가?"), 사극 말투, 한지 톤 UI
- 대상: 전주 방문 관광객(모바일 우선). 데스크탑 화면도 지원. **실제 모바일 기기 검증은 미실시**

## 2. 사용자 여정과 콘텐츠 (현재 구현)

### 2.1 진입 순서 (C02~C05, R04)
`시작하기` → 로그인(ID·가입·게스트·Google·카카오·네이버) → 튜토리얼(오늘 숨김이면 생략) → 이름·생년월일·권한 안내 확인 → 지도

- 로그인은 시연용입니다. 이름 기본값 외에 체험과 연결되지 않습니다(C32).

### 2.2 추천 동선 (C09, C49)

| 순서 | 거점 | 조각 | 인증 반경(GPS 보조 경로) |
| --- | --- | --- | --- |
| ① | 완판본문화관 | 이야기 | 240m |
| ② | 경기전 | 시대 | 220m |
| ③ | 남부시장 | 소지품 | 240m |
| ④ | 전라감영 | 신분 | 220m |
| ⑤ | 국립전주박물관 | 조각 4개 후 결과 | 300m |

- 순서는 추천일 뿐 자유 방문입니다. 새 체험의 기본 선택 거점은 완판본문화관입니다(C08).
- **인증 방식:** 거점 QR 값이 일치하면 그 자리에서 조각과 쿠폰을 지급합니다(GPS 검사 없음). QR 없이 도착 인증 화면을 쓰면 GPS 반경으로 확인합니다. 박물관은 조각 4개를 모아야 열리며, 이 판정은 모두 브라우저 안에서 합니다(C11~C13).
- **한계:** QR 값이 공개 단축 URL이라 현장 방문 증명으로 쓸 수 없습니다(BUG-01).

### 2.3 조각과 결과의 결정 방식 (C16~C19)
- **조각 4종의 문구:** 5개 원형(암행어사·감영 관리·목판 각수·장터 상인·수문장) 중 하나에서 가져옵니다. 원형은 `생년월일 · 첫 방문 거점 · 세션 ID 앞 8자`의 해시로 정해집니다.
- **최종 결과(이미지·음성·스토리):** JSON에 있는 캐릭터 중 무작위로 고르고 그 탭에서 고정합니다. 원형과는 연결되지 않습니다. 현재 1종이라 모든 사용자의 결과가 같습니다(BUG-06, BUG-07).
- 얼굴 분석, 사진 촬영, AI 초상 생성은 없습니다.

### 2.4 쿠폰과 기념품 (모두 시연)
- **쿠폰:** 거점 1곳당 1장, 4개 카테고리 × 3종 = 12종 템플릿 중 무작위(중복 회피), CODE128 시연 바코드. 실제 제휴처 아님(C21~C23).
- **기념품:** 14종(11,000~49,000원). 도장 4개 후 열림. 결제는 1.6초 후 완료 화면을 보여 주는 시연이며 PG 연동·주문 저장·청구가 없습니다(C24~C26).
- **운영 대시보드:** 하드코딩 가상 수치 + 같은 브라우저 탭의 시연 기록 1건(C27). 실측 성과가 아닙니다.

### 2.5 미디어월 (C34~C37)
- 고정 영상 `mediawall.mp4`(H.264/AAC)를 전체 화면으로 재생합니다.
- 전시 동의(Yes/No)는 이 브라우저의 localStorage에 항목을 저장·삭제하는 것까지만 구현되어 있습니다. 저장 목록을 표시하는 화면이 없고, 영상 내용이나 박물관 디스플레이에 반영되지 않습니다.

## 3. 시스템 구조와 기술 스택

### 3.1 기술 스택 (C44)

| 구분 | 내용 (package.json 선언 → bun.lock 해석 버전) |
| --- | --- |
| 프론트엔드 | React ^19.0.1 → 19.3.1, Vite ^8.3.0 → 8.3.8, TypeScript ^7.0.2 → 7.0.2, Tailwind CSS ^4.3.3 → 4.3.5, lucide-react, motion |
| 브라우저 기능 라이브러리 | jsqr(QR 해독), jsbarcode(CODE128) |
| 코드에만 있는 서버 경로 | Express 4(→4.22.3) `server.ts`, Node 내장 SQLite(`.data/jeonsaeng.db`), `@google/genai` — **현재 배포에서 실행되지 않음** |
| 서체 | Pretendard·Noto Sans KR·SangSangRock (외부 CDN) |
| 패키지 매니저 | bun (`bun.lock`) |

### 3.2 명령 (package.json)
- `dev`: `tsx server.ts` (Express + Vite 개발 서버)
- `build`: `vite build` → `dist`
- `lint`: `tsc --noEmit` (현재 오류 12건, R01)
- 테스트 스크립트는 없음. `bun test`로 실행(45건 중 4건 실패, R02)

### 3.3 구조 (C15, C40, C42, C43)

```
[브라우저]
  React 앱 ── apiFetch('/api/...') ──> routeLocal (같은 브라우저 안의 함수)
                                          └─ sessionStorage / localStorage
  정적 파일: /videos, /characters, /goods, /places
[Vercel]
  dist 정적 파일 제공 + 확장자 없는 경로를 index.html로 rewrite
  (서버리스 함수·DB 없음)
[코드에만 존재, 미사용]
  server.ts(Express) + SQLite 파일 DB + Gemini
  supabase/proposals/*.sql (설계 초안)
```

### 3.4 화면 라우팅
URL은 `/`, `/wall`, `/admin` 3개이고, 앱 안은 장면(SceneId 1~11) 전환으로 동작합니다(C06, C07).

### 3.5 저장과 개인정보 (C33, C34, C38, R05)
- sessionStorage: 체험 세션(이름·생년월일 포함), 로그인 정보, 고정 캐릭터 — 보통 탭을 닫으면 사라짐(탭 복원 시 예외 가능)
- localStorage: 로컬 계정(비밀번호 해시), 전시 목록(이름 앞 6자 포함), 직전 캐릭터, 튜토리얼 숨김
- 서비스 서버로 보내는 데이터 없음(로컬 빌드 네트워크 확인). QR 카메라·이미지는 저장·전송하지 않음
- 로그인 비밀번호 해시는 시연용 수준(솔트 없는 SHA-256)이며 보안 인증 체계가 아닙니다(BUG-03)

### 3.6 배포
- 배포 대상은 Vite 정적 빌드(`dist`)입니다. 설정 파일 `vercel.json`(C43)
- **Production URL·배포 커밋·Production 동작은 이 문서 작성 시점에 확인하지 못했습니다.** 배포가 완료되었다는 사실은 사용자 전달 정보입니다.
- Vercel 배포는 정적 웹 호스팅이며, 백엔드·DB 구축을 의미하지 않습니다.
